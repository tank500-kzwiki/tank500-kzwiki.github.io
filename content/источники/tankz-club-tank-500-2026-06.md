# TANKZ Club: топик Tank 500, июнь 2026

Источник: `raw/tankz-club/tank-500/2026-06.md`
Период: 2026-06-01 — 2026-06-30 (первый проход до 06-16; дельта-разбор 06-21—06-30 добавлен 2026-08-10)
Сообщений: ~300

## Основные темы

- **Пинки АКПП (9AT)** — после обновления у ОД снова пинки (Diyas Valikhan, Полат, V E @terkskaikos);
  адаптация 200–300 км + езда на разных режимах; смазка кардана части владельцев не помогает; кастомный
  режим «Эксперт» с мягкими настройками (Режим вождения «Лёгкий», ESC ALL_ON) как смягчающий workaround
  → [[пинки-коробки]]. Фото: `9at-настройки-эксперт-лёгкий.jpg` (экран «Эксперт» NORMAL+)
- **Антифриз** — по сервисной книжке G12+ / G12++ → [[faq]]
- **Чехлы/накидки в салон** — совет брать на заказ у ателье (готовые «колхоз»); накидки Cantra KZ
  (@Rikkar) — единичное упоминание, в вики не выносилось
- **Ароматизация почти не пахнет** (2026-06-09) — несколько владельцев: из дефлекторов запах не идёт,
  хотя картриджи пахнут; сделано намеренно слабым, производитель признал; картридж можно разобрать и
  залить свой парфюм → создана [[ароматизация-салона]], строка в [[норма-или-неисправность]] и [[faq]]
- **Брод «по самое лобовое»** (2026-06-09) — T500 притонул и подмыло при переправе; вывод «брод выше
  порогов крайне не рекомендован» → [[полный-привод]] (предостережение)
- **Коды ошибок P1835 / P2903** (2026-06-10) — соленоид блокировки/раздатки и система 4WD (трактовка
  из онлайн-источников, дилером не подтверждена) → [[полный-привод]] (коды ошибок раздатки/4WD)

### Дельта 2026-06-13 — 06-16

- **Пинки 9AT — продолжение** (2026-06-14/15): 0 ТО 101→102 убирает неадекватную педаль, пинки почти
  нет, но не идеально (Adminzzz); догоняющий удар при сбросе накатом ~37–40 км/ч остаётся на всех
  версиях (Полат, Нуржан); у ОД только 102, шьют только АКПП; адаптация 2–3 тыс. км; смазка = шлицы
  кардана ~20 мин → [[пинки-коробки]] (раздел 2026-06)
- **Откат назад при трогании** (2026-06-15) — несколько владельцев; обходной путь — держать AutoHold
  включённым → [[пинки-коробки]]
- **Софтовые глюки на скорости** (2026-06-15) — пропажа тяги на ~130 км/ч при обгоне (ИБ @ig_bl) и
  непереключение режимов 4WD (Adminzzz) лечатся перезапуском двигателя → [[пинки-коробки]]
- **Запах бензина снаружи + расход 29 л** (2026-06-15) — A @rxknt, Azik @ZhanAzik (Black); подозрение на
  повторную утечку после замены трубок, совет проверить адсорбер бака → [[троение-bt]], [[расход-топлива]]
- **Расход 10,4 л/100 км** (2026-06-15) — serg, трасса-серпантин+горы+город без пробок; фото БК добавлено
  → [[расход-топлива]] (`расход-после-старта-10-4.jpg`)
- **Камеры 360 как регистратор** (2026-06-16) — на стоянке нет, в движении есть; прошивка «пилят в
  России» (Dmitriy Saparkin) → [[видеорегистраторы]]

  межсервисно каждые 5000 км; потемнение масла к 5000 км — норма из-за GDI; для Алматы предпочитают
  5W-30, 0W-30 считают «водой» → [[масло-и-фильтры]]
- **Антикор днища** (2026-06-24 — обсуждение продолжилось в июле) — мнение ARB о ненужности доп.

  отсоединённой фишку электровентиляторов → перегрев/запах проводки; устранил сам → [[алматы]] (Жайык)
- **Спальное место из передних сидений** (2026-06-29) — снимаются передние подголовники (планка на
  клипсах), сиденья раскладываются в ровное; матрас с Pinduoduo/Ozon → [[лайфхаки]]
- **Люстра/балка — прокладка проводов** (2026-06-25) — через дверь багажника + технологическое отверстие
  слева/ниша запаски → [[свет]]
