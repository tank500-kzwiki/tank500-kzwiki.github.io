# TANKZ Club: топик Tank 500, сентябрь 2026

Период: 2026-09-01 — 2026-09-29
Сообщений: ~230

Самый содержательный месяц за полгода: две находки меняют картину по старым темам.

## Основные темы

- **Уровень масла в АКПП как причина пинков** (2026-09-03/05) — у @gucciarmani_009 недолив **1,6 л**,
  после доливки пинки ушли; ещё 3 владельца подтвердили улучшение. Для замера нужен ключ **Mercedes
  9G-Tronic 725.0** (Ozon). → [[пинки-коробки]], [[недолив-масла]], [[масло-и-фильтры]]
- **Прокатка после прошивки** (2026-09-17) — рецепт адаптации: 0→80/90 и обратно до остановки, раз 5;
  коробка адаптируется под город/трассу отдельно. → [[пинки-коробки]]
- **Режим «Авто» помогает не всем** — контрбаланс к августу (R.К. @TSE_RUS, V E @Qasd12dg).
  → [[пинки-коробки]] (фото шайбы режимов)
- **Смазка кардана в регламенте ДЦ Актау** — каждое второе ТО по умолчанию (Роман). → создана
  [[смазка-кардана]]
- **Новая прошивка ГУ (сборка b11)** 2026-09-25 — Яндекс Карты со светофорами, скачивание треков,
  масштаб навигатора; **самостоятельное обновление с флешки** (exFAT → инженерное меню → USB update →
  HUT update, ~20 мин); b11 блокирует сторонние APK — RuStore и файловый менеджер ставить заранее.
  → [[прошивка-гу]], [[carplay]]
- **LKA = признак старой прошивки ГУ** (2026-09-17) — «удержание включается после каждого глушения» →
  ответ сообщества: обновить ГУ. → [[удержание-полосы]]
- **Расход вырос после ТО** у двоих (до 29,9 л на БК) — версия: короткие поездки + автозапуск
  завышают расчёт; второй фактор — доливка масла в АКПП. → [[расход-топлива]]
- **Обдув сидений — только подушка**, спинка не обдувается (из-за массажа). → [[комплектации]]
- **Ароматизатор: «известная проблема»** по версии ARB; картриджи заказывают на Ali/Pinduoduo, иногда
  достаточно снять заводские контрольки. → [[ароматизация-салона]]
- **Утечка антифриза и заблокированный руль** (2026-09-19) — SOS-сообщение; история пробитого
  радиатора. → создана [[радиатор]], дополнены [[уход-антифриза]], [[буксировка-и-эвакуация]]
- **Запчасти ходовой у @AivarKim** — верхняя шаровая только в сборе с рычагом, подшипник полуоси
  комплектом (сальник, запорная втулка, кольцо ABS); блок с головой 1,5 млн тг. → [[алматы]]
- **Бачок омывателя после бампера Meyka** — изготавливают Junk Garage (Алматы) и @kirill_zkg (Брянск).
  → [[лебедка]], [[алматы]]
- **Переходник розетки фаркопа AIRLINE ATE-08** подтверждён повторно. → [[фаркоп]]
- **Русификация T500** — «нет таких, кто предложит — не верьте» (Dmitriy Saparkin, 2026-09-08)
